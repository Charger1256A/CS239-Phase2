# LabCluster starter

The starter includes the original application, an original-app harness and one
scenario with synthetic fixtures and an offline backend. Extend the scenarios
and checks for the assignment.

Read [step_by_step.sh](step_by_step.sh) and run its commands from the repository
root. Running the shell file prints the walkthrough. It creates a fresh workspace
under `runs/`, prepares the original checkout, and walks through generating the
port, reviewing it, translating the harness and running both applications.

Generated ports, review bundles, translated harnesses and results stay in the
ignored workspace. The assignment requires ten scenarios and ten samples each.
